# Azure Storage & Backup Lab

Hands-on Microsoft Azure practical focused on storage management, security,
monitoring, backup and recovery.

This repository documents work completed during my Cloud Administrator
training at CTU. The purpose of the practical was to configure and manage
Azure storage services and work through the data lifecycle from storage
and access through to backup and recovery.

---

## What I worked with

`Microsoft Azure` `Azure Storage` `Blob Storage` `Azure Backup` `SAS`

### Storage

- Created and configured an Azure Storage Account
- Worked with Blob containers
- Configured Zone-Redundant Storage (ZRS)
- Worked with Azure Files
- Managed storage configuration and access

### Data Management

- Configured lifecycle management
- Worked with retention settings
- Managed data across different storage requirements

### Security & Access

- Worked with Shared Access Signatures (SAS)
- Managed controlled access to Azure storage resources
- Reviewed storage security and access configuration

### Monitoring

- Used Azure monitoring tools to review storage activity
- Worked with storage metrics and resource information

### Backup & Recovery

- Configured Azure Backup
- Worked with File Share backup
- Performed backup and restore tasks
- Verified recovery of stored data

---

## What this practical taught me

The useful part of this project was working through more than simply creating
a storage account.

I worked with the wider storage lifecycle: configuration, redundancy, access,
retention, monitoring, backup and recovery.

It also gave me practical experience navigating the Azure portal and
understanding how individual Azure services work together when protecting
business data.
